Query tips for better results:
  - Use specific, literal terms — not paraphrases or full sentences
  - Quote exact phrases: `"error message" library name`
  - Add the year for time-sensitive topics: "feature X release 2026"
  - Include library/framework names and version numbers for technical queries
  - If the first search misses, rephrase with a different angle — never repeat the same query

After getting results:
  - Use webfetch to read the full content of 1–2 key pages when snippets aren't enough
  - Prefer primary sources (official docs, original papers) over aggregators
  - Always cite source URLs in your response
