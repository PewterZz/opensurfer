- Fetches content from a specified URL and returns it as readable text
- Use this tool to read web pages, articles, documentation, and any URL the user shares or mentions

**Use webfetch DIRECTLY (no search needed) for these sites — they have native support:**
- Twitter / X profiles and tweets: `https://x.com/{username}` or `https://x.com/{username}/status/{id}`
- Reddit posts and subreddits: `https://reddit.com/r/{sub}/comments/...` or `https://reddit.com/r/{sub}`
- Hacker News: `https://news.ycombinator.com/item?id={id}` or `https://news.ycombinator.com`
- GitHub: repos, issues, PRs, files, user profiles (set GITHUB_TOKEN for higher rate limits)
- HuggingFace: model cards, datasets, spaces, papers, user/org profiles (set HF_TOKEN for private repos)
- Stack Overflow / Stack Exchange: any question URL
- arXiv: `https://arxiv.org/abs/{id}`
- Research papers: OpenReview (ICLR, NeurIPS), ACL Anthology (ACL/EMNLP/NAACL), CVF (CVPR/ECCV/ICCV), PMLR (ICML/AISTATS), IEEE Xplore, ACM DL — tries open-access versions first, Sci-Hub as last resort
- Wikipedia: any article URL
- YouTube: any video URL (extracts transcript)
- Substack newsletters: `https://{pub}.substack.com` or individual post URLs
- dev.to articles and profiles: `https://dev.to/{username}/{slug}` or `https://dev.to/{username}`
- Lobste.rs stories: `https://lobste.rs/s/{id}` or `https://lobste.rs` for front page
- Instagram public profiles/posts: `https://instagram.com/{username}` or post URLs
- TikTok videos: `https://tiktok.com/@{user}/video/{id}`
- Medium articles: fetched via paywall bypass automatically
- NYT, Washington Post, Bloomberg, FT, WSJ: fetched via archive.ph automatically

Usage notes:
  - The URL must be a fully-formed valid URL starting with https://
  - Format options: "markdown" (default), "text", or "html"
  - For long pages, results are paginated — use page=1, page=2, etc. for subsequent pages
  - This tool is read-only and does not modify any files
